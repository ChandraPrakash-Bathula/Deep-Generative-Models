# From Pixels to Latent Spaces

**Understanding Autoencoders and Variational Autoencoders.** An experimental, visual-first journey through representation learning and generative modelling, built from my own trained models on brain MRI (IXI) and faces (CelebA).

[**Read it online**](https://chandraprakash-bathula.github.io/Deep-Generative-models/) · [Experiment Explorer](https://chandraprakash-bathula.github.io/Deep-Generative-models/explorer.html) · [Live demo (Hugging Face Space)](https://huggingface.co/spaces/ChandraPrakashBathula/medlatent-studio)

This is **Part 1** of a series on deep generative models. Next: diffusion models, world models and JEPA.

## The experiments

- **39 models**: Autoencoder, VAE β = 0.1 and VAE β = 1, with latent sizes 2, 3, 4, 8, 16, 64, 128 (IXI) and 2, 4, 8, 16, 64, 128 (CelebA).
- **Same protocol everywhere**: identical 5-stage convolutional encoder/decoder, AdamW, cosine schedule, augmentation and early stopping. Only the latent layer and β change.
- **Metrics**: MSE, PSNR, foreground PSNR, SSIM, FID of reconstructions and samples (with a real-vs-real floor), active latent units, KL.
